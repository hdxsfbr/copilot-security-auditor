# Key metrics and evidence rules

Product claim: an authorized operator can repeatedly discover, substantiate and track Clinical Co-Pilot boundary failures across explicit target versions at a known operational cost. The numbers below test that claim. They are **definitions and intended acceptance measurements**, not achieved baselines. The September 28 [audit](docs/audit/2026-09-28/AUDIT.md) found unscoped counts and judgment/report gaps, so no current “safe rate” should be presented as a reliable product metric.

| Metric | Definition and denominator | Why it matters; evidence and current status |
| --- | --- | --- |
| **Supported distinct findings** | Count unique, current-version, reproduced violations with complete action/evidence links, a reviewed or calibrated confirmation route, and independent boundary proof where required. Report by category and severity; show pending/unsupported separately. | Measures useful discovery without rewarding duplicate candidates or model assertions. Current finding schema and gate cannot establish this; [E01](https://linear.app/hdxsfbr/issue/HDX-7), [E02](https://linear.app/hdxsfbr/issue/HDX-8), [E03](https://linear.app/hdxsfbr/issue/HDX-10), [G01](https://linear.app/hdxsfbr/issue/HDX-26) are prerequisites. The rubric's three real reports remain unverified. |
| **Reproduction and fix verdict quality** | For each confirmed attack/version pair, `reproduced with same boundary and evidence criterion / eligible completed replays`; separately count `fixed`, `recurring`, `resurfaced`, `unknown`. Never include blocked/incomplete as fixed or failed. | A finding that cannot recur or whose fix is inferred from wording is not actionable. Current one-at-a-time replay is partial; [G02](https://linear.app/hdxsfbr/issue/HDX-27) adds suites and explicit version lineage. |
| **Judge calibration** | On a frozen, labeled synthetic set, report confusion matrix by policy/model version: false auto-confirm rate over safe/echo/refusal controls; false-safe rate over genuine fixture violations; abstention over ambiguous cases. Record corpus size and confidence intervals, never a naked percent. | False confirmation and false assurance both damage trust. Target thresholds must be chosen before live scoring; automatic confirmation is disabled for a policy until the calibration gate is justified. Current exact-quote gate is uncalibrated; [E03](https://linear.app/hdxsfbr/issue/HDX-10) owns evidence. |
| **Versioned exercised coverage** | For target/version/time and category/subcategory: `executed and assessable case definitions / eligible published case definitions`; also report attempted, blocked, incomplete, adjudicated and untested counts. Separate direct/indirect/multi-turn and OWASP tags; no safe-rate denominator includes unknown evidence. | Reveals blind spots and whether resilience comparisons use the same scope. Current global query mixes targets and execution states; [C01](https://linear.app/hdxsfbr/issue/HDX-15), [V01](https://linear.app/hdxsfbr/issue/HDX-24), [V02](https://linear.app/hdxsfbr/issue/HDX-25) own repair. |
| **Bounded operating cost and throughput** | Per run and role: settled provider charge, unresolved hold, reservation, tokens and latency. For 100-case fixture and separately authorized live runs: wall time, p50/p95 case/LLM latency, CPU/memory peak, storage throughput, queue age and incomplete rate; report 100/1K/10K/100K assumptions and actual development spend separately. | Determines whether continuous evaluation can be operated without hidden charge or backlog. Ledger exists, but no 100-case live baseline or actual dev-spend record is available. [M02](https://linear.app/hdxsfbr/issue/HDX-28), [O01](https://linear.app/hdxsfbr/issue/HDX-21), [P01](https://linear.app/hdxsfbr/issue/HDX-32), [L02](https://linear.app/hdxsfbr/issue/HDX-37) own evidence. |

Each chart or export must show sample size, target/version, case-definition version, evidence mode (black-box or approved read-only corroboration), time window and policy version. Comparing unlike scopes is prohibited. A rise in attempted cases or model calls is not success by itself. Report target outcomes and human finding disposition separately; a confirmed finding does not retroactively change an execution's observed response. [Q02](https://linear.app/hdxsfbr/issue/HDX-30) will record fixture acceptance, and [D02](https://linear.app/hdxsfbr/issue/HDX-33) will update measured values and remaining gaps.
