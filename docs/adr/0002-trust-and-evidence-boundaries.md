# ADR 0002: User-facing attacks, explicit proof limits and human publication authority

- **Status:** accepted design; current gaps tracked as issues.
- **Date:** 2026-09-29.

The later [Co-Pilot feature brief](../../docs/COPILOT_FEATURE.md) and [audit decision](../../docs/audit/2026-09-28/AUDIT.md) define cross-patient success as **chart-context isolation**. A physician's ability to open another chart separately is legitimate. We attack only with authorized synthetic user-facing chat or PDF actions. The worker owns saved identity, chart selection, OpenEMR handshake, ticketed turns and bounded retry; no model may select an endpoint, credential, patient or arbitrary HTTP request. The existing host allowlist limits dispatch, while LAN restriction is the current operator access boundary.

Judgment must name its evidence mode. Black-box user-visible responses can establish a disclosed fact only when the fact and wrong-chart provenance are grounded; an echoed ID, source-shaped prose or a model's unsupported claim is insufficient. The current report fingerprint is a narrow indicator, not proof that no write happened anywhere. An incomplete or truncated observation cannot support a complete/safe result. [E01](https://linear.app/hdxsfbr/issue/HDX-7) preserves response structure and completeness; [E03](https://linear.app/hdxsfbr/issue/HDX-10) links claims to executed actions and checked evidence; [E02](https://linear.app/hdxsfbr/issue/HDX-8) gates review/export on actual artifact integrity.

The user approved an **optional read-only evidence adapter** in the [delivery plan](../implementation/audit-delivery/PLAN.md). [X01](https://linear.app/hdxsfbr/issue/HDX-34) may add a separately approved, version-bound contract for seeded facts and correlated audit events. It is disabled by default and cannot write, choose arbitrary targets, or turn a missing/stale event into proof of no effect. This design permission does not grant access to target source, live endpoints or credentials. Black-box execution remains useful with honest unknown outcomes.

Human review handles unsupported or uncertain findings; report publication requires separate approval of the exact redacted revision. The Documentation model may draft from confirmed evidence, but cannot confirm a finding, introduce new facts or publish. A later disappearance of evidence does not erase a historical decision; it blocks a new complete/reproducible claim until restored. No automated target patch or deployment is in scope. [F01](https://linear.app/hdxsfbr/issue/HDX-22) and [F02](https://linear.app/hdxsfbr/issue/HDX-23) own those lifecycle gates.
